# Canvas RPG

## Chronoscope (time-travel civilization sandbox)
The new heart of this repo lives in [`timetraveler/`](timetraveler/README.md): a **completely deterministic**
world where civilizations rise and fall through simple emergent rules. Travel back in time, make a small change,
and watch how the future rewrites itself. Open `timetraveler/index.html` in a browser; run the tests with
`node timetraveler/test/run.js`.

## About (legacy engine)
This project has been pieced together to be an engine for a top-down RPG that renders on a canvas tag. It is in no working order at the moment, but it has been fun to piece together. The legacy engine is in `JS/` and is loaded by the root `index.html`.
